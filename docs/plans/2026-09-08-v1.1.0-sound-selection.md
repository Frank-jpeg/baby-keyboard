# 宝宝键盘 v1.1.0：八种音色与小键盘选择

## 操作

- 单独长按 Esc 3 秒，提示“松手退出”，全部键鼠按钮松开后关闭。
- 右侧小键盘 1～8 直接选择：水晶、钢琴、木琴、八音盒、水滴、泡泡、复古游戏、星空魔法。
- Num Lock 开或关都按数字所在的物理位置；主键盘数字、独立导航键和回车保持普通互动效果。
- 同一数字长按只响应一次，松开后可以再选。每次启动默认水晶，不保存输入或设置。

## 实现

保留已有 WPF 星空、按键光环和粒子。底部增加音色名称、简短描述和带小键盘数字的八个提示；当前项高亮，切换后短暂加强边框亮度。

根据扫描码与扩展标记区分小键盘导航位置和独立导航键。音色与选择版本保存在输入线程的快照中，视觉事件队列拥堵不丢失最终选择。按扫描码跟踪物理键，兼容 Num Lock / Shift 引起的虚拟键码变化。

音频线程预生成八种音色、八个五声音阶音高的小波形库。不同音色分别使用金属泛音、琴弦泛音、木质敲击、八音盒、滑音水滴、泡泡、有限谐波电子琶音和延迟星光音。采用柔和起音、尾部渐隐、八声部限制与混音限幅；切换时旧声音 40 毫秒淡出。音频设备失效不影响选择、画面和保护。

版本目录独立发布 EXE、中文说明、预览和试听 WAV，并保留 v1.0.0。源码随 Git 提交归档。

## 验收

Esc 短按、长按、启动残留、多键取消与全松手退出；回车不触发控制；八个小键盘位置在 Num Lock 开关状态下均选择正确；长按不重复选择；后台输入不穿透；音色清晰区分且混音稳定；继承原有看护与异常恢复验证。实际结果见 [验证记录](../VERIFICATION.md)。
