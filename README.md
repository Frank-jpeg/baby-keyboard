# 宝宝键盘

给小朋友随意敲键盘的 Windows 全屏互动软件。按键变成发光字符、光环与粒子，配柔和短音；键盘输入和鼠标按钮、滚轮不会传给后面的程序。

**退出：单独长按回车 3 秒，进度满后松开所有按键。** 主回车、小键盘回车均可。中途按其他键或鼠标按钮会取消，需要松开回车再试；连续敲击不累计。启动时已经按住的回车必须先松开。

## 使用

打开发布包中的 `宝宝键盘-v1.0.0.exe` 即可，不需要 Python、管理员权限或另外安装 .NET。首次启动需要解开内置运行组件，可能稍慢。程序离线运行，不保存按键记录，也不添加开机启动。

默认柔和音效已开启，软件不修改系统音量。没有可用音频设备时自动静音，键鼠保护和画面照常工作。鼠标左、右、中、侧键点击均产生光圈；滚轮操作被拦截。

紧急恢复：`Ctrl + Alt + Delete` → **锁定**，重新登录。收到锁屏、会话断开或休眠通知时软件会退出。另有独立看护进程；主界面或输入线程连续约 5 秒不再响应时，它会结束主程序并恢复光标范围。正常退出时看护也会结束。

用途是防幼儿误触。系统安全桌面、电源键、部分 Fn 硬件功能、触控板的系统级多指手势不保证拦截；持续单独按住回车 3 秒也能解除。其他应用自己弹出的通知或定时动作不属于键鼠拦截范围。

## 开发与打包

- C# / .NET 10 / WPF，面向 Windows 11 x64；没有额外 NuGet 库依赖。
- 工作区内的 SDK：`../tools/dotnet10/dotnet.exe`。也可安装 .NET 10 SDK 后通过 `-SdkPath` 指定。
- `build.ps1` 编译、运行核心测试，发布包含运行组件的单文件 EXE，并生成预览与分发 ZIP。
- `build.ps1 -NativeTests` 额外对发布 EXE 运行真实键鼠集成测试。**会短暂接管键鼠和显示全屏界面**，每次都有最多 45 秒的独立超时保护。
- 发布结果位于 `artifacts/release/`。图标已在源码中，普通编译不需要 Python；只有重新生成图标时才需要 Pillow。
- 分发 ZIP 同时包含 .NET 运行组件的许可和第三方声明 `RUNTIME-NOTICES.txt`。

```powershell
.\build.ps1
.\build.ps1 -NativeTests
.\build.ps1 -SdkPath 'C:\Program Files\dotnet\dotnet.exe'
```

可选预览：`宝宝键盘-v1.0.0.exe --preview` 打开普通窗口，不安装全局钩子；按 Esc 或关闭窗口退出。

## 结构和保护措施

- `src/BabyKeyboard.Core`：不依赖界面的解锁状态机、键帽名称、离线音色合成。使用单调时钟，区分按下、重复与松开。
- `src/BabyKeyboard.App`：全屏窗口、每个显示器的 DPI 布局、Win32 键鼠钩子、看护进程、PCM 播放与动画。
- `tests/BabyKeyboard.Tests`：核心断言与 Windows 原生集成测试，不依赖测试服务或网络。

输入钩子在单独的消息循环线程中运行；不做磁盘、音频、绘图或同步 UI 调用。视觉队列最多 128 个事件，画面最多保留 32 个短暂特效；音效独立播放，限制为约每秒 8 次、最多 4 声部，合成音量受限。鼠标在主屏边缘以内活动，所有显示器都有覆盖窗口。

看护通过仅当前用户可访问的本地命名管道接收界面与输入线程的进展，只结束 PID 和启动时间都匹配的主进程。锁屏和故障退出优先恢复输入；正常手势退出等待所有按键松开，避免把残余回车传给后台窗口。钩子安装失败会回滚已经安装的部分。

测试中的键鼠事件有专用标记，先发送到独立的无编辑功能测试窗口。一个更早安装的只读观察钩子验证事件是否穿透；运行时不保存用户按键。卡死与钩子故障注入参数只能与有硬超时的测试模式一起使用。

验证结果和未覆盖的硬件场景见 [验证记录](docs/VERIFICATION.md)。
