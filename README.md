# 宝宝键盘

给小朋友随意敲键盘的 Windows 全屏互动软件。按键变成发光字符、光环与粒子，配柔和短音；键盘输入和鼠标按钮、滚轮不会传给后面的程序。

**退出：单独长按 Esc 3 秒，看到“松手退出”后松开所有按键和鼠标按钮。** 也可以在右下角 Esc 说明区域按住鼠标左键约 3 秒退出。中途按其他键或鼠标按钮会取消，需要松开 Esc 再试；连续敲击不累计。启动时已经按住的 Esc 必须先松开。

v1.1.2 增加右下角 Esc 说明区域的鼠标长按备用退出；并保留特殊按键恢复逻辑。如果退出被其他按键打断，屏幕会提示先全部松手，再重新长按 Esc。

v1.1.3 增加小键盘 9 号的“八色混合”音色，把 1～8 混合播放。

**切换音色：按小键盘 1～9，直接选择。** 9 是 1～8 八种音色混合的声音。Num Lock 开、关都支持，屏幕会高亮当前音色。主键盘数字、独立方向键、主回车和小键盘回车都是普通互动按键。按住小键盘数字不会反复切换，松开后可以再选。

| 小键盘 | 音色 | 听感 |
| --- | --- | --- |
| 1 | 清脆水晶 | 轻盈、清亮的小铃声 |
| 2 | 轻柔钢琴 | 温暖的琴弦与柔和余音 |
| 3 | 童趣木琴 | 短促、圆润的木质敲击 |
| 4 | 叮咚八音盒 | 高一些的童话铃音 |
| 5 | 灵动水滴 | 滴答落下的小水珠 |
| 6 | 弹跳泡泡 | 轻轻弹起的“啵”声 |
| 7 | 复古游戏 | 柔和的电子小琶音 |
| 8 | 星空魔法 | 依次闪烁、渐渐散开的星光 |

## 使用

打开发布包中的 `宝宝键盘-v1.2.0.exe` 即可，不需要 Python、管理员权限或另外安装 .NET。首次启动需要解开内置运行组件，可能稍慢。程序离线运行，不保存按键记录，也不添加开机启动。

默认使用清脆水晶，每次打开从音色 1 开始。九种声音均为本地合成，不使用网络音频素材；按键落在协调的五声音阶内，切换时旧声音短暂淡出，新音色自动试听。软件保持低音量，不修改系统音量。没有可用音频设备时自动静音，音色选择、键鼠保护和画面照常工作。鼠标左、右、中、侧键点击均产生光圈；滚轮操作被拦截。

发布包附 `sound-preview.wav`，按 1～9 的顺序各播放三个音符，方便提前试听。

紧急恢复：`Ctrl + Alt + Delete` → **锁定**，重新登录。收到锁屏、会话断开或休眠通知时软件会退出。另有独立看护进程；主界面或输入线程连续约 5 秒不再响应时，它会结束主程序并恢复光标范围。正常退出时看护也会结束。

用途是防幼儿误触。系统安全桌面、电源键、部分 Fn 硬件功能、触控板的系统级多指手势不保证拦截；持续单独按住 Esc 3 秒也能解除。其他应用自己弹出的通知或定时动作不属于键鼠拦截范围。

## 开发与打包

- 仓库：https://github.com/Frank-jpeg/baby-keyboard
- C# / .NET 10 / WPF，面向 Windows 11 x64；没有额外 NuGet 库依赖。
- 工作区内的 SDK：`../tools/dotnet10/dotnet.exe`。也可安装 .NET 10 SDK 后通过 `-SdkPath` 指定。
- `build.ps1` 编译、运行核心测试，发布包含运行组件的单文件 EXE，并生成预览与分发 ZIP。
- `build.ps1 -NativeTests` 额外对发布 EXE 运行真实键鼠集成测试。**会短暂接管键鼠和显示全屏界面**，每次都有最多 45 秒的独立超时保护。
- 发布结果位于 `artifacts/release/v1.2.0/`，按版本分目录，保留旧版文件。图标已在源码中，普通编译不需要 Python；只有重新生成图标时才需要 Pillow。
- 分发 ZIP 同时包含 .NET 运行组件的许可和第三方声明 `RUNTIME-NOTICES.txt`。

```powershell
.\build.ps1
.\build.ps1 -NativeTests
.\build.ps1 -SdkPath 'C:\Program Files\dotnet\dotnet.exe'
```

可选预览：`宝宝键盘-v1.2.0.exe --preview` 打开普通窗口，不安装全局钩子；可按小键盘 1～9 试听，长按 Esc 3 秒或关闭窗口退出。

## 结构和保护措施

- `src/BabyKeyboard.Core`：不依赖界面的解锁状态机、键帽名称、离线音色合成。使用单调时钟，区分按下、重复与松开。
- `src/BabyKeyboard.App`：全屏窗口、每个显示器的 DPI 布局、Win32 键鼠钩子、看护进程、PCM 播放与动画。
- `tests/BabyKeyboard.Tests`：核心断言与 Windows 原生集成测试，不依赖测试服务或网络。

输入钩子在单独的消息循环线程中运行；不做磁盘、音频、绘图或同步 UI 调用。视觉队列最多 128 个事件，画面最多保留 32 个短暂特效。音色选择通过独立状态快照传递，不会因视觉队列满而丢失；按扫描码区分小键盘与导航键。音效在独立线程预计算和播放，16 个排队音符、最多 8 声部，同一音色每 120 毫秒最多触发一次；切换时有 40 毫秒淡出，合成音量受限。鼠标在主屏边缘以内活动，所有显示器都有覆盖窗口。

看护通过仅当前用户可访问的本地命名管道接收界面与输入线程的进展，只结束 PID 和启动时间都匹配的主进程。锁屏和故障退出优先恢复输入；正常手势退出等待所有按键松开，避免把残余按键传给后台窗口。钩子安装失败会回滚已经安装的部分。

Pause/Break 和文本包按瞬时动作处理，不依赖可能缺失的松开消息；键盘溢出标记、Print Screen 附带的扩展 Shift 不计入物理按键。对驱动前缀、左右修饰键别名、重复按下以及松开时缺失或变化的扫描码进行归一和匹配，避免积累残留状态。鼠标启动状态按系统左右键设置映射。

`GetAsyncKeyState` 只用于启动前的状态采样。输入钩子吞掉按下消息后，Windows 的异步键位状态不会更新，因此不能用它定时清空实际仍按住的键。单独运行退出回归测试：编译后执行 `BabyKeyboard.Tests.exe --unlock-regression <EXE 路径>`，每个保护实例仍有独立超时。

测试中的键鼠事件有专用标记，先发送到独立的无编辑功能测试窗口。一个更早安装的只读观察钩子验证事件是否穿透；运行时不保存用户按键。原生验证会暂时切换 Num Lock，并在结束后恢复原状态。音色状态查询、卡死与钩子故障注入仅在有硬超时的测试模式启用。

验证结果和未覆盖的硬件场景见 [验证记录](docs/VERIFICATION.md)。


v1.2.0 定时休息：启动前选择 3 / 5 / 10 分钟，或自定义 1～60 分钟，每次默认 5 分钟。最后 30 秒提醒，到点后显示皮卡丘休息页，声音淡出，按键和点击不再产生特效。休息页继续保护键鼠；单独长按 Esc 3 秒并松开，或在右下角退出区域按住鼠标左键约 3 秒，均可退出。不会自动返回游玩；重新打开可开始下一轮。
